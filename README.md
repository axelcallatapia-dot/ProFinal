# AutoVista

Tienda en línea de vehículos premium con rutas públicas, carrito de compras, estado global con Pinia y panel de administración.

## Características

- Inicio con llamado a la acción para comprar o ver el dashboard.
- Páginas de Nosotros, Catálogo, Carrito y Administración.
- Carrito global gestionado con Pinia.
- Datos simulados de 5 productos con stock y ventas.
- Diseño responsivo y moderno con Bootstrap.

## Ejecutar localmente

```sh
npm install
npm run dev
```

## Construir para producción

```sh
npm run build
```

## Probar el estado del carrito

```sh
npm run test -- --run
```
